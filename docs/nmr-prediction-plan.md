# WA Chem ¹H/¹³C NMR 预测与交互谱图实施计划

状态：已纳入路线，尚未开始产品实现
最后更新：2026-09-21

## 1. 最终目标

对当前单一分子结构同时提供 ¹H 与 ¹³C NMR 预测，结果不是一张不可解释的谱图图片，而是一组可追溯、可选择、可导出的结构化数据：

- 带稳定原子编号的结构；
- 逐原子或等价原子组的化学位移、置信度/适用域和指认；
- ¹H 的积分、多重性与可用时的耦合常数；
- 可缩放谱图、峰表，以及结构↔峰↔表格三向联动；
- 核种、溶剂、仪器频率、温度、provider、模型/数据版本和输入结构版本；
- 明确的成功、部分结果、不支持、超出适用域和失败状态。

Web 与 Apple app 使用同一产品语义和冻结样例。Apple 基础预测和谱图绘制必须原生运行；不依赖 Python、JVM、WebView、sidecar 或联网服务才可完成。

## 2. 化学边界

- 第一版只处理单一、确定连接关系的小分子；混合物、聚合物、Markush、金属配位物和未确定立体化学可明确拒绝；
- ¹H 与 ¹³C 分开评测和报告，不能用其中一个核种的质量代表另一个；
- 化学位移预测与谱线模拟是两层能力。没有可靠耦合常数时，¹H 只能展示位移、积分、峰表和明确标注的简化谱，不伪造实验级裂分；
- 预测谱不得标成实测谱。界面必须显示预测来源、条件、误差口径和适用域；
- 结构编辑后旧结果立即过期；旧任务完成时不得覆盖新结构版本；
- 不以一张服务端 PNG 作为数据源，渲染必须来自结构化峰与指认结果。

## 3. 共享结果契约

产品层依赖一个与具体模型隔离的接口：

```text
predictNMR(structure, nuclei, conditions, options) -> NMRPredictionResult
```

结果至少包含：

- `status`: `success | partial | unsupported | outOfDomain | failed`；
- `provider`、`providerVersion`、`modelVersion`、`datasetVersion`；
- `sourceStructureVersion`、规范化结构校验和、原子 ID 映射；
- `nucleus`: `1H | 13C`，以及溶剂、频率、温度和参考标准；
- `assignments`: 原子/等价组、预测位移、置信区间或不确定度；
- ¹H 的积分、多重性、耦合常数及各字段是否为预测/推导/不可用；
- `peaks` 与可选的模拟谱线参数，而不是预渲染位图；
- 适用域告警、未指认原子、失败阶段和运行耗时。

Web 和 Apple 对同一分子的稳定原子 ID 可以不同，但必须通过共享测试向量映射到相同化学原子。缓存键包含规范化结构、核种、条件和模型版本。

## 4. 内部实施步骤

这些步骤是工程验证顺序，不是对用户分批开放。¹H 与 ¹³C 都达到各自门槛前，完整功能入口保持关闭。

### Step 0：候选模型、许可证与冻结数据集

工作：

1. 分别筛选 ¹H、¹³C 的候选模型/算法，记录训练数据来源、商用分发许可、权重许可、支持元素和立体化学边界；
2. 建立按官能团、环系、杂原子、分子量和难度分层的冻结训练外测试集；
3. 保留实验条件和原子指认；无法确认指认质量的数据不得进入精确率门槛；
4. 在 Web 目标主机和 Apple 目标设备测量模型大小、内存、P50/P95 延迟与能耗；
5. 确定 Apple 可转换为 Core ML 或可用 Swift/Accelerate 原生实现的候选，不把 Python 可运行等同于 Apple 可交付。

退出条件：每个核种至少有一个许可证可分发、数据口径可解释且可在目标平台运行的候选；否则本阶段停止，不先造 UI。

### Step 1：原子映射与共享结果模型

工作：

1. 定义结构规范化、显式/隐式氢展开、等价原子组和稳定原子映射；
2. 在 TypeScript/Python 与 Swift 中实现同一 JSON 结果契约；
3. 把预测任务绑定到 `ChemDocument` 结构版本，支持取消、过期丢弃、缓存和结构化错误；
4. 为溶剂、频率、温度、参考标准和单位定义受控枚举与默认值；
5. 建立 ¹H/¹³C 合成测试向量，覆盖对称性、同位素、电荷、芳香性和立体中心。

退出条件：双端能无损加载相同结果并指向正确原子；快速连续编辑不会让旧结果覆盖新文档。

### Step 2：Web 本地预测 provider

工作：

1. 在服务器科学计算模块封装 ¹H/¹³C provider，固定依赖、权重和版本校验和；
2. 实现超时、并发、输入上限、缓存、健康检查和管理员开关；
3. 预测输出转换为共享契约，禁止前端直接依赖模型私有张量或字段；
4. 对每个核种生成冻结集 MAE/RMSE、指认完整率、适用域失败率和延迟报告；
5. 服务不可用时返回正式错误，不阻塞编辑、保存、OCSR 或其他化学功能。

退出条件：服务器离线可运行；重启后版本与缓存可追溯；两个核种均有独立验收报告。

### Step 3：Apple 原生预测引擎

工作：

1. 将通过 Step 0 的模型转换并锁定为 Core ML，或以 Swift/Accelerate/Metal 实现等价推理；
2. 在共享 `apple-core` 中实现特征构建、推理、原子映射、取消和结果缓存，iOS、iPadOS、Mac Catalyst 不复制三套业务逻辑；
3. 对转换前后模型运行逐样例差分测试，量化浮点精度导致的位移差异；
4. 检查 app 包、进程和网络，证明基础预测不包含 Python/JVM/WebView/sidecar，也不依赖 Web API；
5. 对内存紧张和不支持设备提供明确失败或禁用态，不偷偷改走网络。

退出条件：Apple 与参考模型在冻结集上的差异处于预先冻结的容差内；三个 Apple 形态均可从当前源码的新鲜产物完成预测。

### Step 4：峰生成与原生谱图渲染

工作：

1. 从指认与条件生成 ¹³C stick spectrum 和 ¹H 峰/积分表示；
2. 只有 provider 给出可靠多重性或耦合常数时才模拟精细裂分；否则标记为简化谱；
3. Web 使用浏览器原生画布/SVG，Apple 使用 SwiftUI/Metal/Core Graphics 原生绘制；
4. 实现 ppm 反向坐标、缩放、平移、重置、峰标签、碰撞处理和辅助功能；
5. 结构原子、峰和表格共享选择状态，高亮不改变化学文档。

退出条件：两个核种的峰位置、积分/强度口径和选择映射通过黄金测试；大峰表交互不阻塞主线程。

### Step 5：化学验证与双端一致性

工作：

1. ¹H、¹³C 分别统计 MAE、RMSE、分位误差、异常值、指认完整率和适用域覆盖率；
2. 按官能团、元素、环系、分子量和立体化学分层，避免总体均值掩盖系统性失败；
3. Web 与 Apple 对相同模型、结构和条件比较逐原子结果；
4. 由化学人员复核对称性、交换性质子、互变异构和带电结构等高风险样例；
5. 新失败先进入冻结回归集，再调整模型、特征或结果规则。

最低发布门槛必须在 Step 0 后根据候选模型和数据集冻结；不得在看到结果后降低门槛。误差、覆盖率和拒绝率分开报告。

### Step 6：一次性接入产品界面

工作：

1. Web 与 Apple 同时增加 ¹H/¹³C 切换、条件选择、计算、取消和重算入口；
2. 同屏展示编号结构、谱图和峰表，提供结构↔峰↔表格三向选择；
3. 显示预测/简化谱标识、provider、模型版本、条件、误差口径和适用域告警；
4. 导出结构化 CSV/JSON 峰表以及 SVG/PNG 谱图；如增加 JCAMP-DX，须先冻结字段与兼容性测试；
5. 保存文档时只保存可追溯结果和版本，不把过期结果当作当前预测。

退出条件：Mac Catalyst、iPhone、iPad 与 Web 使用同一场景完成两个核种的计算、联动、取消、过期和导出；VoiceOver/键盘基础操作可用。

### Step 7：打包、发布与运行时证明

工作：

1. 将权重、许可证、第三方通知、模型卡、数据/适用域说明纳入对应产物；
2. 验证 Web 镜像架构、权重校验和、健康检查和目标机真实推理；
3. 验证 Apple app 包依赖、离线预测、当前源码新鲜构建和实际运行进程路径；
4. 按统一发布规则构建所有发生变化的组件，并回归独立部署、VOS 和 Apple 产品线；
5. 发布说明列出两个核种的条件、门槛、误差、覆盖范围和已知限制。

退出条件：冻结报告、许可证、包内容、双端运行时和发布产物均有可复核证据；任一核种未达门槛时，不把完整 NMR 功能标记为可用。

## 5. 进度记录规则

每完成一步，在本文件对应步骤下追加：

- 完成日期与提交；
- 实际修改模块、模型和权重校验和；
- 测试命令、数据集版本与结果文件；
- 分层误差、覆盖率、延迟和资源数据；
- 新增限制与下一步唯一入口。

按钮存在、静态谱图出现、单个样例合理或模型能在 Python 中运行，都不能把某一步标记为完成。
