# 资产、账户与 SDF 交互模型

本文件定义 WA Chem 的账户归属、资产层级和 SDF 操作语义。Web 与 Apple app 必须按同一套规则实现；Apple app 是一个统一产品层，桌面与触控只允许作为系统输入、系统文件能力和生命周期适配入口。

## 账户与数据归属

- Apple app 使用当前 Apple 系统账户的数据空间保存文档、本地 SDF 资产和 WA-DD 连接信息。默认开启 iCloud 同步；用户可在设置中关闭。iCloud Drive 不可用或关闭同步时，回落到本机容器。连接、切换或断开 WA-DD 不迁移、不覆盖这些本地数据。
- Apple app 的 WA-DD 连接地址、用户名、本地资产索引和文档草稿可通过 iCloud 文件同步；WA-DD 登录 token 不写入普通文件，必须走系统 Keychain，并在可用时使用 iCloud Keychain synchronizable item。用户未开启 iCloud Keychain 时只在本机保留 token，跨设备需要重新登录。
- Web 独立部署使用 WA Chem 自己的账户作为主身份。用户可以直接注册 WA Chem 账户；之后连接 WA-DD 只是在该 WA Chem 用户下新增或更新一个远端连接，不改变已经创建的文档和本地资产。
- Web 第一次通过 WA-DD 登录时，可以创建一个 WA Chem 用户空间；后续再连接新的 WA-DD 服务器仍保持同一个 WA Chem 用户空间，除非用户明确退出并登录另一个 WA Chem 账户。
- Web 的用户文档、连接记录和本地 SDF 资产属于 Docker 映射数据目录，容器重建不得丢失。
- VOS 版使用 OIDC 得到 VOS 同名 WA Chem 用户，并自动发现同 Docker 网络内的 WA-DD；自动连接失败时保留 WA Chem 用户空间，不回退成临时匿名数据。

## Apple App Store 交付

- Apple app 按同一个 App Store Connect 产品管理，用户购买/获取一次后可在 Apple 设备上使用。
- Apple app 必须使用同一个 `top.fuluwa.wa-chem` Bundle ID 命名空间；版本号必须由 `update_version.sh` 同步，不允许手工维护两个不一致的版本。
- 本地直装/公证包和 App Store 包可以使用不同签名与分发流程，但文档格式、资产语义、WA-DD 连接语义和 About 版本显示必须一致。
- App Store 版必须启用 `iCloud.top.fuluwa.wa-chem` iCloud Documents entitlement，并保留未登录 iCloud 或未开启 iCloud Drive 时的本机 fallback。

## 资产层级

右侧资产窗口必须常驻显示层级关系：

```text
本地资产
  SDF 资产 A
    分子 1
    分子 2
  SDF 资产 B
    分子 1
WA-DD 服务器
  服务器 A
    项目
      配体资产
        分子
  服务器 B
    项目
      配体资产
        分子
```

- 本地资产与 WA-DD 服务器是并列根节点。
- 本地 SDF 资产可以新建，不限于默认资产。
- 选中一个资产后，可以把画布内容追加到该资产；选中资产中的一个分子后，可以打开到画布编辑，也可以用当前画布保存覆盖该分子。
- WA-DD 资产的打开、保存、追加和导出通过 WA-DD API 完成；本地资产通过本地持久化完成。
- 本地或 WA-DD 导入 `.sdf/.sd` 时，必须新建一个资产，并把文件中的每条有效 SDF record 作为资产下的一个分子；不能只把首条丢到画布，也不能把整个 SDF 当成单画布文件。

## 打开、保存、追加

- 打开资产中的分子：把该分子载入当前画布，并按当前画布大小自动居中/适配。
- Handoff 打开 iCloud 中的 `.wachem` 文档或本地 SDF 资产时，Apple app 应打开同一个 iCloud 文件/资产索引；不另行复制一份分子结构状态。只有非 iCloud 位置或 WA-DD 远端资产需要通过导入/API 拉取结构。
- 保存：只在选中某个已存在分子时可执行，用当前画布或当前选中分子覆盖该资产分子。
- 追加：不要求先保存当前文档。追加写入的是当前画布状态的快照，追加完成后不改变当前画布，也不修改已打开资产中的原记录。
- 未选中任何结构或全选时，追加把当前画布作为一个分子 record 写入目标资产。
- 选中单个连通分子时，追加只写入该分子。
- 选中原子/键且没有覆盖完整连通分子时，追加写入选中片段。

## SDF 导出

- 导出一个本地 SDF 资产：把该资产中的所有分子合并为一个多 record `.sdf` 文件。
- 导出一个 WA-DD 配体资产：拉取该资产所有分子结构，并合并为一个多 record `.sdf` 文件。
- 导出当前画布为 SDF：如果画布上有多个互不相连的分子，按连通分量拆成多个 SDF records；如果只有一个分子，则导出单 record。
- Web 导出行为是下载文件；Apple app 导出行为是弹出系统保存面板，可保存到本地或 iCloud。
- Web 导入本地 SDF 的行为是上传文件内容并创建当前 WA Chem 用户下的新本地资产；导入到 WA-DD 项目时，上传为该项目下的新配体资产。
- Apple app 导入本地 SDF 的行为是通过系统文件选择器读取文件并创建本地新资产；导入到 WA-DD 项目时，读取本地文件并通过 WA-DD API 新建远端配体资产。

## 输入适配

- Apple app 的业务动作必须来自共享产品层。桌面输入适配提供右键、鼠标/触控板、键盘和悬停快捷键；触控输入适配提供长按、触摸和 Pencil。两种输入适配暴露同等动作，不得维护不同业务状态。
- Web 右键菜单和触屏长按也必须暴露同等动作；实现可以使用浏览器 API，但资产和化学语义不得分叉。
